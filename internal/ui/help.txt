TUnIversalCalc — calculadora TUI
================================

Flujo rápido
------------
1. En el panel 1 declara un objeto o escribe un entero.
   Ejemplos: 120, /puntos (1,2) (3,4), /funcion 2x+2.
2. Pulsa Enter: el objeto se guarda con auto-nombre.
3. En el panel 2 escribe la operación sobre ese objeto.
4. La salida paso a paso aparece en el panel derecho.

Panel 1 — declaración
---------------------
  /puntos (1,2) (3,4) (5,6)   Puntos para interpolar
  /funcion 2x+2               Función sin "="
  /expresion x^2+1            Expresión sin "="
  /ecuacion 2x+2=0            Ecuación con un "="

Auto-nombres: e1 (ecuación), f1 (función), p1 (expresión),
t1 (puntos). El comando /lagrange o /newton puede citar el objeto
(/newton t1) o usar el último declarado.

Panel 2 — operaciones
---------------------
  /lagrange [objeto]   Polinomio interpolador de Lagrange
  /newton   [objeto]   Interpolación por diferencias divididas
  /factorizar [obj]    Factoriza enteros, polinomios o fracciones
  /factorizar -cuadrado [objeto]  Completa el cuadrado de una cuadrática
  /desarrollar [obj]   Desarrollo de productos notables
  /potencia [objeto]   Simplificación exacta de potencias
  /radical  [objeto]   Simplificación exacta de radicales
  /radicalizar [objeto] Racionaliza fracciones con raíces
  /limpiar             Borra objetos, historial, salida e inputs

/limpiar funciona desde cualquier panel y pide confirmación (s/N).
Al confirmar, la sesión actual se guarda vacía y no hay Ctrl+Z.

Un /expresion con un entero literal (por ejemplo /expresion 120)
muestra automáticamente su factorización.

/potencia, /radical y /radicalizar operan sobre la expresión completa:
  /expresion (3a^3b^3)(4ab^2)^2      → /potencia
  /expresion sqrt(200)-sqrt(32)     → /radical
  /expresion sqrt(10)/(sqrt(5)-2)   → /radicalizar
  /expresion (sqrt(4+h)-2)/h        → /radicalizar
  /expresion (a+b)^2                → /desarrollar
  /expresion 2x^2+5x-12             → /factorizar
  /expresion (x^2-1)/(x-1)          → /factorizar
  /expresion 2x^2-12x+11            → /factorizar -cuadrado
/factorizar combina fracciones algebraicas, factoriza numerador y
denominador y cancela los factores comunes.
/factorizar -cuadrado reescribe ax^2+bx+c como a(x-h)^2+k, muestra
el proceso y el vértice. Requiere una sola variable y coeficientes
racionales.
/radicalizar multiplica por el conjugado cuando el numerador o el
denominador es un binomio con raíces cuadradas; después simplifica y
cancela factores comunes.
Para extraer una raíz nueva, declara raiz(expr) o raiz(n, expr);
/radical se encarga de simplificarla.

Matemáticas exactas
-------------------
El motor exacto de /potencia, /radical y /radicalizar usa fracciones y
exponentes racionales (sin float): 3/2, -1/2, raíces y coeficientes
exactos.
  sqrt(200)        → 10·√2
  raiz(9)          → 3
  raiz(3, 16)      → 2·∛2
  x^(3/2)          → x√x
  (2x)^-2          → 1/(4x^2)

/factorizar acepta fracciones de polinomios con exponentes enteros:
combina las operaciones, factoriza ambos polinomios y cancela.

Variables: una letra (x), o nombres de tres o más letras (alpha,
beta, tasa). Dos letras seguidas siguen siendo un producto: ab = a*b.
Para multiplicar variables usa * o un espacio: alpha*beta.
Ante paréntesis, escribe alpha*(beta+1) (sin espacio no se admite
como multiplicación implícita).
Funciones: sqrt, sin, cos, abs, raiz. También pi e inf.
Las raíces pares asumen variables positivas: sqrt(x^2) = x.

Paleta de comandos
------------------
Escribe "/" para abrir la paleta. Filtra con fuzzy match, navega con
↑/↓ o Tab/Shift+Tab, inserta con Enter y cierra con Esc.

Atajos
------
  Tab              Cambiar de panel
  Shift+Tab        Saltar al siguiente campo "?"
  Enter            Guardar declaración o ejecutar operación
  ↑/↓              Historial (panel 2) o navegar la paleta
  PgUp/PgDn        Scroll del panel de salida
  Ctrl+H           Abrir/cerrar esta ayuda
  Ctrl+L           Abrir la confirmación para limpiar todo
  Ctrl+O           Selector de sesiones
  Ctrl+Space       Autocompletar funciones, constantes u objetos
  Ctrl+Z / Ctrl+Y  Deshacer / rehacer
  Ctrl+S           Guardar la sesión ahora
  F2               Copiar la salida al portapapeles
  Esc / Ctrl+C     Cerrar la ayuda/paleta o salir

Sesiones
--------
El trabajo se guarda automáticamente cada 30 segundos en
$XDG_DATA_HOME/tuniversalcalc/sessions (o ~/.local/share/...).
Al salir también se guarda. Puedes abrir una sesión concreta con:

  tuniversalcalc --session "mi sesión"
  tuniversalcalc --new
  tuniversalcalc --list

En el selector (Ctrl+O): ↑/↓ navega, Enter abre, Ctrl+R renombra,
Ctrl+U duplica, Ctrl+D borra (y confirma), Esc cierra.

Matemáticas
-----------
El parser acepta + - * / ^, paréntesis, multiplicación implícita
(2x, x(y+1)), sqrt, raiz(x), raiz(n, x), sin, cos, abs, pi e inf.
Variables de una letra o nombres de tres o más letras. La salida
muestra LaTeX emulado y una versión Unicode legible.
